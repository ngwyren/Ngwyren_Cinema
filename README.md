# Ngwyren Cinema

Web xem phim Vietsub, giao diện đen trắng kiểu Apple TV.

**[Xem ngay](https://ngwyren.github.io/Ngwyren_Cinema/)** · [Bản phát hành](https://github.com/ngwyren/Ngwyren_Cinema/releases)

## Tính năng

- Hơn 1.600 phim lẻ, phim bộ và anime, có trọn bộ Studio Ghibli
- Nhiều nguồn phát Vietsub, lồng tiếng và thuyết minh
- Chọn chất lượng đến 4K, tự cắt quảng cáo chèn trong phim
- Lưu tiến độ xem và danh sách yêu thích
- Dùng tốt trên điện thoại, iPad và máy tính

## Chạy trên máy

Mở `Run-Ngwyren-Cinema-App.bat`, hoặc phục vụ thư mục này bằng một máy chủ tĩnh bất kỳ.

## Cấu trúc

| Đường dẫn | Nội dung |
| --- | --- |
| `index.html` | Trang chính |
| `css/style.css` | Giao diện |
| `js/movies-catalog.js` | Kho phim |
| `js/data.js` | Nạp dữ liệu, tìm kiếm, gợi ý |
| `js/modules/` | Trình phát, trang phim, điều hướng, đồng bộ tài khoản |
| `scripts/` | Cập nhật kho phim tự động |
